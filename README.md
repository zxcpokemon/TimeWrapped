# TimeWrapped

Локальная статистика времени для **Windows 10/11 x64**. Версия **1.1.0**.

TimeWrapped отдельно показывает время работы ПК, приложения на экране и в фоне, музыку и посещённые сайты. Данные хранятся на вашем компьютере. Основной учёт работает без регистрации и облака.

## Что изменилось в 1.1

- История сайтов выглядит как история браузера: дата, время посещения, название страницы и адрес.
- Возврат к вкладке не создаёт новое посещение. Новый переход или перезагрузка страницы создаёт отдельную запись.
- Длительность показывается суммарно по сайтам, а не у каждой строки истории. Есть поиск, фильтр сайта и группировка по дням.
- Старые дробные записи сгруппированы по странице; исходные интервалы и суммарное время сохранены. Точные переходы старых версий восстановить невозможно, поэтому старая группировка приблизительная.
- Русский, английский и украинский интерфейсы. Язык выбирается в настройках и сохраняется после перезапуска. В браузерной панели можно выбрать язык отдельно.

## Возможности

- Независимые счётчики времени ПК, сна, блокировки, простоя и активного фокуса.
- Обычные окна любого размера на всех мониторах. Видимость учитывается по геометрии и перекрытию; несколько окон одного приложения не умножают его время.
- Раздельное время на экране, только в фоне и всего запущено. Службы, обновления, anti-cheat и вспомогательные процессы не показываются как самостоятельные приложения.
- История за выбранный период, категории, исключения, Weekly Wrapped и PNG-карточка.
- Настраиваемый автозапуск в трее или с открытым окном.
- Spotify: локальное воспроизведение через Windows SMTC и активную незаглушённую аудиосессию; названия треков и исполнители сохраняются после отдельного включения.
- SoundCloud: название, исполнитель и время воспроизведения через одно браузерное дополнение. Системная громкость браузера не проверяется.
- История сайтов и отдельная добровольно включаемая статистика 18+. Последняя остаётся в личном разделе и не попадает в обычную PNG-карточку.
- Жанры исполнителей вручную или через необязательный запрос MusicBrainz.
- Dota 2: публичные данные OpenDota, матчи, форма, герои и напарники; ссылки на Dotabuff и STRATZ.
- FACEIT CS2: публичный режим без ключа или официальный Data API с собственным ключом. Для Dota/FACEIT достаточно Steam-ссылки или SteamID64, вход в Steam через приложение не нужен.

## Установка

Готовые файлы можно приложить к GitHub Releases:

- `TimeWrapped_1.1.0_x64-setup.exe` — установщик для текущего пользователя.
- `TimeWrapped.exe` — переносимый запуск.
- `TimeWrapped-Browser-1.1.0.zip` — единое дополнение Chrome/Edge.

Для интерфейса нужен Microsoft Edge WebView2 Runtime. Установщик предложит загрузить его, если он отсутствует. Для внешних игровых сервисов и MusicBrainz требуется интернет; основной учёт локальный. Сборка не имеет цифровой подписи.

Перед обновлением закройте прежнее окно приложения и запустите новую версию. Сборщик сохраняет буфер и обновляется штатно. Автозапуск включается в настройках. Закрытие окна оставляет сборщик в трее; «Полностью выйти» завершает сбор.

## Браузерное дополнение

1. Откройте **Расширения → Браузер**, сохраните ZIP и распакуйте в постоянную папку.
2. В `edge://extensions` или `chrome://extensions` включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Закрепите значок TimeWrapped, вставьте код из приложения и нажмите «Подключить».
4. Включите нужные функции. История сайтов требует отдельного разрешения браузера на вкладки и сайты.

Для обновления замените файлы **в той же папке** и нажмите ↻ у существующего дополнения. Не устанавливайте новую копию из каждой папки. Постоянный ID и разрешения сохранены. Подробности — в [инструкции дополнения](browser-extension/README.md).

История начинается после включения, прошлые посещения браузера не импортируются. Инкогнито не собирается. Посещения и время независимы: открытие страницы добавляет посещение, а длительность растёт только у активной вкладки окна с фокусом. Сон, блокировка и пауза не добавляют время сайта.

По умолчанию сохраняются домены и время. Для названий и адресов страниц включите «Сохранять названия и пути страниц». Служебные query-параметры, фрагменты URL, пароли и содержимое страниц не записываются. Для YouTube сохраняется только ID видео, чтобы его можно было открыть из истории. Старые видео без сохранённого ID открыть точно невозможно.

## Языки

В **Настройки → Язык приложения** доступны Русский, English и Українська. Меняются интерфейс, категории, единицы времени, даты, итоги и меню трея. Названия приложений, треков, исполнителей и страниц не переводятся. Нативные элементы системных диалогов могут использовать язык Windows.

В браузерной панели отдельный селектор языка. Если отдельный выбор не сохранён, используется язык приложения.

## Данные и обновление

```text
%LOCALAPPDATA%\TimeWrapped\activity.sqlite3
%LOCALAPPDATA%\TimeWrapped\extensions.sqlite3
```

В 1.1 основная база получает схему 5, предотвращающую небезопасный запуск старых версий. Перед обновлением существующей базы создаётся `activity.pre-v1.1.sqlite3`; перед переносом накопленной истории сайтов — `extensions.pre-v1.1.sqlite3`. Исходные интервалы не удаляются и не переписываются. Миграция посещений выполняется один раз.

Конфигурация дополнений, жанры, игровые профили и защищённые ключи сохраняются. API-ключ FACEIT защищён Windows DPAPI. Код браузера хранится только локально; не публикуйте его или базы данных. Полное удаление истории и отдельное удаление 18+ удаляют соответствующие записи и принадлежащие приложению миграционные копии.

JSON/CSV экспорт основного учёта не включает секреты и браузерную историю. Изменение категорий и исключений применяется к накопленным отчётам; общее время ПК остаётся независимым.

## Сборка

Требуются Windows x64, Node.js 22+, Rust MSVC, Visual Studio C++ Build Tools с Windows SDK и WebView2 Runtime.

```powershell
npm ci
npm run check
node --test tests/*.test.mjs
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run build -- --ci
```

Результаты — `src-tauri/target/release/TimeWrapped.exe` и `src-tauri/target/release/bundle/nsis/TimeWrapped_1.1.0_x64-setup.exe`. GitHub Actions запускает проверки и сборку в Windows. Локальная подготовительная папка `work` в репозиторий не входит.

Общий каталог переводов находится в `src/translations.mjs`. `scripts/sync-i18n.mjs` синхронизирует его с браузерным дополнением и нативным меню. Проверки выявляют устаревшие копии переводов.

## Проверки и ограничения

Результаты и границы проверки описаны в [VALIDATION.md](VALIDATION.md), устройство приложения — в [CONTRACT.md](CONTRACT.md).

TimeWrapped измеряет наблюдаемую работу ПК, геометрию окон и состояние плееров, а не внимание человека. Для полного дня включите автозапуск: пропущенную работу приложений восстановить достоверно нельзя. Сумма времени видимых приложений может превышать время ПК, когда несколько приложений видны одновременно.

Необычная прозрачность и форма окон могут оцениваться приблизительно. Spotify не различает музыку, рекламу и подкасты. Длинные интервалы SoundCloud без подтверждённого продвижения позиции пропускаются. Доступность публичных игровых интерфейсов зависит от сервисов; при ошибке сохраняется последний успешный снимок.

При создании issue укажите версию Windows и приложения, число мониторов, шаги воспроизведения и ожидаемое поведение. Не прикладывайте личные базы или код подключения.
