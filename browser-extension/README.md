# TimeWrapped Browser 1.1.0

Одно дополнение Chrome / Edge 120+ для Windows-приложения TimeWrapped 1.1.0.

1. Распакуйте ZIP в постоянную папку.
2. В chrome://extensions или edge://extensions включите режим разработчика → «Загрузить распакованное расширение».
3. Закрепите значок, вставьте код из «Расширения → Браузер» и нажмите «Подключить».
4. Включите сайты и/или SoundCloud. Для всех сайтов браузер отдельно запрашивает разрешение.

Для обновления замените файлы в той же папке и нажмите ↻ у существующего TimeWrapped. Постоянный ID и разрешения сохранены, вторая копия не нужна. Обновите также Windows-приложение до 1.1.0 для нового вида истории.

## История

Новый переход создаёт посещение; возврат к открытой вкладке продолжает таймер сайта. Открытая в фоне страница может появиться в истории, но не получает активное время. Время показывается суммарно по сайтам. История прошедших посещений браузера не импортируется, инкогнито не учитывается.

По умолчанию сохраняются домены. Названия и пути включаются отдельно. Пароли, служебные query-параметры и фрагменты URL отбрасываются; для YouTube остаётся только ID видео, нужный для открытия страницы. Содержимое страниц не передаётся.

## Музыка

SoundCloud передаёт название, исполнителя и позицию плеера. Резервная фоновая проверка работает даже при замедлении таймера вкладки; неопределённые длинные интервалы не выдумываются. Настольный Spotify измеряет Windows-приложение. Общая пауза останавливает сбор; браузерная пауза останавливает сайты и SoundCloud.

## Язык и подключение

Русский, English и Українська выбираются в панели. Без отдельного выбора используется язык приложения. Код хранится локально и не синхронизируется. Данные отправляются только на 127.0.0.1:38671 с проверкой кода; не публикуйте код.

Подключение не ждёт внедрения скриптов во вкладки. Если служба или вкладка не отвечает, действует ограничение ожидания и доступна повторная попытка. Установку и разрешения выдаёт пользователь, автоматического управления другими дополнениями нет.
